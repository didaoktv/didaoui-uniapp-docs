# 间距

帝到 KTV 采用 **4px 基础栅格**的 8 级间距系统。等级按几何级数递增，**刻意省略 20px 与 40px 中间值**，保证布局节奏可预测——任何间距都只能是这 8 个值之一，杜绝随意取值。

::: tip 设计哲学
少即是多。8 个值覆盖从图标-标签 4px 到页面区块 64px 的全部场景。设计师与开发者无需记忆任意中间值，间距即栅格。
:::

---

## 间距阶梯

| Token | 值 | rpx (750rpx = 屏宽) | 典型用途 |
| --- | --- | --- | --- |
| `--space-1` | `4px` | `8rpx` | 图标-标签间隙、卡片内部细隙 |
| `--space-2` | `8px` | `16rpx` | 紧凑组件内边距、标签组间隙 |
| `--space-3` | `12px` | `24rpx` | 卡片内边距、列表项间隙 |
| `--space-4` | `16px` | `32rpx` | **默认内边距**、卡片间距 |
| `--space-5` | `24px` | `48rpx` | 区块内边距、卡片组间距 |
| `--space-6` | `32px` | `64rpx` | 大区块间距、分区留白 |
| `--space-7` | `48px` | `96rpx` | 页面级分区留白 |
| `--space-8` | `64px` | `128rpx` | 顶部/底部大留白、英雄区上下 |

```css
:root {
  --space-1: 4px;
  --space-2: 8px;
  --space-3: 12px;
  --space-4: 16px;
  --space-5: 24px;
  --space-6: 32px;
  --space-7: 48px;
  --space-8: 64px;
}
```

---

## 8pt 栅格基础

所有间距都是 **4px 的整数倍**，构成 8pt 栅格体系：

- **基础单位**：4px（`--space-1`）
- **栅格单位**：8px（`--space-2`），是布局的最小可读节奏
- **递进规则**：4 → 8 → 12 → 16 → 24 → 32 → 48 → 64，相邻比约 1.33-1.5
- **缺失值**：系统**不提供** 20px / 40px，需要时用 `space-4 (16)` 或 `space-5 (24)` 替代

```
┌── 4 ──┬── 8 ──┬── 12 ──┬── 16 ──┬── 24 ──┬── 32 ──┬── 48 ──┬── 64 ──┐
│ s-1   │ s-2   │ s-3    │ s-4    │ s-5    │ s-6    │ s-7    │ s-8    │
└───────┴───────┴────────┴────────┴────────┴────────┴────────┴────────┘
```

## rpx 换算

uni-app 多端开发中，小程序使用 `rpx` 响应式单位。换算基准为 **750rpx = 屏幕宽度**。

以 iPhone 6（375px 逻辑像素）为基准：

```
1px  = 2rpx
1rpx = 0.5px
```

换算公式：

```
rpx = px × (750 / 屏幕宽度px)
```

由于设计稿通常以 375px 宽为基准，**px 与 rpx 的换算比为 1:2**：

| px | rpx |
| --- | --- |
| 4 | 8 |
| 8 | 16 |
| 12 | 24 |
| 16 | 32 |
| 24 | 48 |
| 32 | 64 |
| 48 | 96 |
| 64 | 128 |

::: warning 多端取值
- **H5 / App**：直接使用 `px`，CSS 变量已定义为 px 值。
- **小程序**：建议在 `uni.scss` 中以 `rpx` 重定义间距变量，或依赖 uni-app 的 `px` 自动转换（`uni.scss` 中配置）。
- **设计稿**：以 375px 宽设计稿为准，1px = 2rpx。
:::

## 尺寸 Token

间距之外，系统定义了组件尺寸 token，与间距体系协同：

| Token | 值 | 用途 |
| --- | --- | --- |
| `--size-icon-sm` | `16px` | 小图标 |
| `--size-icon-md` | `20px` | 默认图标 |
| `--size-icon-lg` | `24px` | 大图标 |
| `--size-icon-xl` | `32px` | 特大图标 |
| `--size-button-sm` | `32px` | 紧凑按钮高度 |
| `--size-button-md` | `44px` | **默认按钮高度** |
| `--size-button-lg` | `50px` | 大按钮高度 |
| `--size-input-height` | `44px` | 输入框高度 |

> ponytail: `button-md` 与 `input-height` 同为 44px 但语义不同（按钮 vs 输入框），`button-sm` 与 `icon-xl` 同为 32px 同理——语义别名优于魔法数字。

```css
:root {
  --size-icon-sm: 16px;
  --size-icon-md: 20px;
  --size-icon-lg: 24px;
  --size-button-sm: 32px;
  --size-icon-xl: 32px;
  --size-button-md: 44px;
  --size-input-height: 44px;
  --size-button-lg: 50px;
}
```

## 使用准则

- **只用 token**：禁止 `padding: 13px` 这类非栅格值，一律走 `--space-*`。
- **图标-标签**：`--space-1` (4px) 紧贴，`--space-2` (8px) 留隙。
- **卡片内边距**：默认 `--space-4` (16px)，紧凑卡片用 `--space-3` (12px)。
- **区块间距**：卡片组之间 `--space-5` (24px)，页面分区 `--space-6` (32px) 起步。
- **按钮高度**：默认 `--size-button-md` (44px)，符合 44pt 触控目标最低要求。
- **不混用 px 与 rpx**：同一组件内统一单位，避免小程序端布局抖动。
