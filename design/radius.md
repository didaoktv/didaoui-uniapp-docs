# 圆角

帝到 KTV 的圆角体系对齐 Vant 4 的小圆角尺度，同时融入抖音商城的柔和观感——**越柔和越显高级**。6 级圆角从 2px 细微倒角到 9999px 全圆，覆盖从紧凑标签到圆形头像的全部场景。较大的圆角（xl/2xl）用于卡片与底部弹层，传递包容感与可触近性。

::: tip 设计哲学
圆角是「含蓄的奢华」。在纯黑背景上，大圆角的卡片边界更柔和，减少硬边缘的攻击性；而 pill 形（full）则用于搜索框、标签等需要强调亲和力的元素。Vant 式小圆角保证信息密度场景（列表、表单）的克制。
:::

## 圆角阶梯

| Token | 值 | 用途 |
| --- | --- | --- |
| `--radius-sm` | `2px` | 细微倒角：小标签、徽标数字角 |
| `--radius-md` | `4px` | 紧凑控件：小按钮、复选框 |
| `--radius-lg` | `8px` | 标准控件：按钮、输入框、小卡片 |
| `--radius-xl` | `12px` | 卡片、模态框、标准容器 |
| `--radius-2xl` | `16px` | 大卡片、特色内容、底部弹层 |
| `--radius-full` | `9999px` | pill 形：搜索框、标签、圆形头像 |

```css
:root {
  --radius-sm: 2px;
  --radius-md: 4px;
  --radius-lg: 8px;
  --radius-xl: 12px;
  --radius-2xl: 16px;
  --radius-full: 9999px;
}
```

## 抖音商城风设计理念

帝到 KTV 的圆角策略融合两种取向：

### 1. Vant 式克制（sm / md / lg）

信息密度场景使用小圆角，保持界面克制与专业：

- **复选框**：`radius-md` (4px) —— 方形特征，与圆形单选形成对比
- **按钮 / 输入框**：`radius-lg` (8px) —— 标准控件，柔和但不抢戏
- **小标签**：`radius-sm` (2px) —— 紧凑信息块

### 2. 抖音商城式柔和（xl / 2xl / full）

容器与强调元素使用大圆角，传递高级感与亲和力：

- **标准卡片**：`radius-xl` (12px) —— 比传统 8px 更柔和
- **底部弹层 / 模态**：`radius-2xl` (16px) —— 顶部大圆角，弱化边界
- **搜索框 / 标签**：`radius-full` (9999px) —— pill 形，最具亲和力
- **头像 / 图标**：`radius-full` —— 圆形，符合社交场景

::: warning 全圆角的特殊用法
`radius-full` 在系统中仅用于 pill 形元素与圆形元素。**搜索框是唯一使用 full 圆角的输入控件**，配合左侧图标槽，形成抖音商城式的胶囊搜索条。其余输入框使用 `radius-lg`。
:::

## 使用准则

- **控件用 lg，容器用 xl/2xl**：按钮/输入框统一 `radius-lg`，卡片/弹层用 `xl` 或 `2xl`。
- **pill 仅限亲和元素**：搜索框、标签、头像、开关、步进器用 `full`，正文按钮不用。
- **同层级圆角一致**：同一卡片组内的卡片圆角必须统一，避免视觉错乱。
- **嵌套递减**：容器圆角应大于内部元素圆角（如 `2xl` 容器内放 `lg` 按钮），形成层次。
- **不自定义中间值**：禁止 `border-radius: 10px` 这类非 token 值，一律走 `--radius-*`。
- **底部弹层顶部圆角**：底部弹层仅顶部两角使用 `2xl`，底部为直角，贴合屏幕底边。
